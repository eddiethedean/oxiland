## User-visible result (target)

At the end of 0.3, a Rust caller can:

- configure parsed queries with base IRI, limit, offset, and features;
- consume boolean, bindings, graph, and syntax result forms;
- stream solution and graph-result iterators without full materialization;
- run SPARQL Update and select datasets explicitly;
- serialize results in Redland-supported formats where practical;
- look up variables by name and position with explicit unbound semantics;
- observe a documented cancellation/timeout policy (even if initially
  unsupported).

## Immediate next actions

1. Inventory Redland query/result/update symbols for the 0.3 slice.
2. Design streaming result adapters over Oxigraph iterators.
3. Record decisions for unbound variables, ordering, and dataset defaults.
4. Add SELECT/CONSTRUCT/DESCRIBE/Update fixtures before freezing public types.

## Non-goals (remain deferred)

- C ABI query handles (0.7+)
- Full protocol/SPARQL endpoint server
- Guaranteeing order where SPARQL does not
