# Milestone 0.10 — Release candidate qualification

Status: in progress

Outcome: freeze the intended 1.0 contracts and qualify 100% Redland parity plus
an every-case performance win

Depends on: 0.9 (complete)

Release evidence: [`docs/reports/0.10.md`](../reports/0.10.md)

The [roadmap](../ROADMAP.md) is normative for the outcome. This document is the
executable work breakdown; it does not weaken either hard gate.

## Frozen scope

- Baseline: Redland `librdf` 1.0.17, manual 1.0.18, source SHA-256 recorded in
  [`0.10-matrix.json`](https://github.com/eddiethedean/oxiland/blob/main/compatibility/qualification/0.10-matrix.json).
- Supported targets: Linux x86-64, macOS Apple Silicon, and Windows x86-64.
- Build profiles: release default (Fjall) and release all-storage.
- Python: CPython 3.10–3.14 wheels on Linux, macOS, and Windows.
- Storage: `memory`, `fjall`, `redb`, `rocksdb`, `sqlite`, and `lmdb`; feature
  names and format-v1 reader policy are frozen by ADR-024.
- Performance: every case in
  [`0.10-suite.json`](https://github.com/eddiethedean/oxiland/blob/main/compatibility/performance/0.10-suite.json) is
  required. A tie, inconclusive interval, or loss blocks the release.

## Qualification commands

```text
python3 scripts/check-inventory.py
python3 scripts/check-0.10-parity.py INVENTORY EVIDENCE --output PARITY_REPORT
python3 scripts/check-performance-gate.py RAW_SAMPLES --output PERFORMANCE_REPORT
python3 -m unittest discover -s scripts/tests
```

The parity checker requires exact matrix coverage, verifies the entire public
symbol denominator per profile, and rejects skips, mismatches, quarantines,
deviations, and every non-verified C row. The performance checker evaluates
each case independently using medians and a deterministic 10,000-round
bootstrap confidence interval. It never averages a loss away.
