# 0.1.0 release checklist

Historical record: this checklist was used before tagging `v0.1.0`. The
repository now contains that tag at commit `98e3f50`; keep this file as release
evidence rather than instructions for a new release.

## Preflight

- [x] `Cargo.toml` version is `0.1.0`
- [x] `CHANGELOG.md` has a `0.1.0` section (Fjall persistence documented)
- [x] `LICENSE-APACHE` and `LICENSE-MIT` are present
- [x] `repository` / `homepage` point at `eddiethedean/oxiland`
- [x] `CARGO_REGISTRY_TOKEN` secret is configured
- [x] Working tree is clean and pushed to `main` (`b7d0aed`)
- [x] Latest CI on `main` is green (Check + Fjall + MSRV)
- [x] `cargo publish --dry-run` succeeds locally

## Local verification

```console
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo doc --no-deps
python3 scripts/check-inventory.py
scripts/generate-public-api.sh check

```

## Publish (historical)

The release was triggered with:

```console

git push origin v0.1.0
```

The Release workflow runs CI then `cargo publish`.
