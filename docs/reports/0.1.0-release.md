# 0.1.0 release checklist

Use this before tagging `v0.1.0`.

## Preflight

- [ ] `Cargo.toml` version is `0.1.0`
- [ ] `CHANGELOG.md` has a `0.1.0` section
- [ ] `LICENSE-APACHE` and `LICENSE-MIT` are present
- [ ] `repository` / `homepage` point at the real GitHub repo
- [ ] `CARGO_REGISTRY_TOKEN` secret is configured (already present)
- [ ] Working tree is clean and pushed to `main`
- [ ] Latest CI on `main` is green (Check + MSRV + RocksDB)

## Local verification

```console
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
cargo doc --no-deps
python3 scripts/check-inventory.py
scripts/generate-public-api.sh check
cargo publish --dry-run
```

Optional RocksDB path:

```console
cargo test --all-features
```

## Publish

```console
git tag -a v0.1.0 -m "oxiland 0.1.0"
git push origin v0.1.0
```

The Release workflow runs CI (including RocksDB) then `cargo publish`.

## After publish

- [ ] Confirm https://crates.io/crates/oxiland
- [ ] Confirm https://docs.rs/oxiland/0.1.0
- [ ] Create a GitHub Release from the `v0.1.0` tag using `CHANGELOG.md`
