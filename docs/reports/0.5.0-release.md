# Oxiland 0.5.0 release checklist

Preflight for tagging `v0.5.0`.

## Preflight

- [x] `Cargo.toml` version is `0.5.0`
- [x] `CHANGELOG.md` has a dated `0.5.0` section
- [x] `docs/reports/0.5.md` describes the compatibility claim
- [x] `PARITY.md` marks 0.5 complete and points at the 0.5 inventory
- [x] `docs/ROADMAP.md` / `docs/milestones/0.5.md` are `complete`
- [x] ADR-013–ADR-016 are accepted
- [x] Public API snapshot includes utility + logging surface
- [x] Example `std_replacements` runs in CI
- [x] `SECURITY.md` supports `0.5.x`
- [x] `LICENSE-APACHE` and `LICENSE-MIT` are present
- [ ] Working tree clean on the release candidate tip after push
- [ ] CI on `main` green (Check + Fjall + MSRV + RDF I/O conformance)
- [x] `cargo publish --dry-run` succeeded on the release candidate
- [ ] Pushed to `main`

## Publish

- [ ] Annotated tag `v0.5.0` pushed (`git tag -a v0.5.0 -m "oxiland 0.5.0"`)
- [ ] Release workflow completed successfully on the tag

## After publish

- [ ] Confirm https://crates.io/crates/oxiland (0.5.0 via Release workflow)
- [ ] Confirm https://docs.rs/oxiland builds for the published crate
- [ ] Create a GitHub Release from the `v0.5.0` tag using `CHANGELOG.md`
