# Milestone 0.10 qualification report

Status: collecting evidence — release blocked

Milestone: [`0.10`](../milestones/0.10.md)

## Implemented stabilization work

- All package manifests are aligned at 0.10.0.
- ADR-024 freezes the supported storage identities, feature names,
  `StorageCapabilities`, and format-v1 reader/export policy and rejects exposing
  the internal durable adapter as a public custom-backend trait for 1.0.
- `supported_backends()` exposes the feature-independent frozen matrix;
  `compiled_backends()` remains build-specific.
- The qualification matrix and benchmark suite are frozen and machine-readable.
- Strict parity and performance report validators have regression tests,
  including tests proving that C exclusions and individual benchmark losses
  block qualification.
- The C ABI now implements and lifecycle-tests named-graph context insertion,
  removal, containment and streams; literal convenience insertion; and
  statement clear/partial-match semantics. The public header and linker
  allowlist contain 108 checked exports.

## Current hard-gate result

Not qualified. The last completed inventory is 0.9 and contains 49 safe-Rust
exclusions plus 214 C exclusions and 74 C `not-applicable` rows. The 0.10
contract requires every in-scope C row to be `verified`, including lifecycle
forms whose ownership mechanics are `not-applicable` only in safe Rust.

No 0.10 parity percentage is published until a complete inventory and all six
target/profile evidence records pass `scripts/check-0.10-parity.py`. No
faster-than-Redland claim is published until raw samples for every frozen case
and performance profile pass `scripts/check-performance-gate.py`.

## Release blockers

- Complete and behaviorally verify the remaining Redland C surface.
- Remove safe-Rust in-scope exclusions or implement their required mapping.
- Run the complete differential, conformance, sanitizer, fuzz, packaging, and
  downstream matrices on all frozen targets/profiles.
- Collect controlled benchmark evidence and pass every required comparison.
- Complete an RC soak without an ABI reset.

The dependency audit is vulnerability-clean under the two narrow R-020
`quick-xml` exceptions, but reports the R-023 maintenance warning for
unmaintained `bincode` 1.3.3 through optional `heed`/LMDB. That warning requires
a release decision even though it is not currently a RustSec vulnerability.

These items cannot be satisfied by relabeling inventory rows, capability
errors, migration workarounds, reduced matrices, or waivers.
