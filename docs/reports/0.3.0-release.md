# Oxiland 0.3.0 release checklist

Preflight for tagging `v0.3.0` (same pattern as
[`0.2.0-release.md`](0.2.0-release.md)).

## Preflight

- [x] `Cargo.toml` version is `0.3.0`
- [x] `CHANGELOG.md` has a dated `0.3.0` section (2026-07-30)
- [x] `docs/reports/0.3.md` describes the compatibility claim
- [x] `PARITY.md` marks 0.3 complete and points at the 0.3 inventory
- [x] `docs/ROADMAP.md` / `docs/milestones/0.3.md` are `complete`
- [x] ADR-009–ADR-012 are accepted
- [x] Public API snapshot includes owned `QueryResults` variants and
  `serialize_graph_results_to_writer`
- [x] Examples `construct` and `update` run in CI
- [x] README / getting-started / positioning list 0.3 SPARQL as available
- [x] `LICENSE-APACHE` and `LICENSE-MIT` are present
- [x] `repository` / `homepage` point at `eddiethedean/oxiland`
- [x] `cargo publish --dry-run` succeeded locally (on a clean tree)
- [ ] Working tree clean and pushed to `main` (fill SHA below after push)
- [ ] CI on `main` green for that commit (Check + Fjall + MSRV + RDF I/O
  conformance)
