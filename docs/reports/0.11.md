# Milestone 0.11 parity report

Status: in progress — full Redland parity is not yet claimed

Milestone: [`0.11`](../milestones/0.11.md)

## Starting position

Oxiland 0.10 completed the public function inventory, implemented a broad C
surface, and checked in qualification scaffolding. The 0.10 checker passes its
own bundle, but that bundle does not prove the full compatibility contract:
profile results were declared from a shared symbol list after local smoke tests
rather than derived from native Redland differential executions on each target.

The 0.11 phase therefore treats all 0.10 `verified` states as candidates for
reverification, not inherited proof.

## Open hard gates

| Gate | State | Required evidence |
|---|---|---|
| Complete baseline denominator | open | Functions, data, types, constants, macros, layouts, callbacks, factories, CLI, and behavioral obligations |
| Native two-sided differential harness | open | Raw Redland and Oxiland observations for the same cases |
| Safe workflow parity | open | Obligation-linked Rust tests and differentials |
| C source compatibility | open | Unchanged-source corpus and downstream builds per target/profile |
| Binary ABI interchange | open | Redland-built binaries run against Oxiland without rebuild |
| Full observable behavior | open | Zero skip/mismatch/deviation/quarantine/capability substitution |
| Cross-platform provenance | open | Independently executed, revision- and artifact-bound raw bundles |
| Candidate safety and conformance | open | Sanitizer, fuzz, W3C, crash, storage, and callback evidence |
| Performance and packaging retention | open | Exact parity candidate retains the frozen gates |
| Independent reproduction and soak | open | Clean verifier reproduces report; no reset or blocker |

## Completion rule

This report becomes `complete` only when the 0.11 checker derives a passing
result from the linked raw evidence for every frozen target and profile. Counts
from an inventory, an export allowlist, or a manually asserted profile result
cannot close a gate.
