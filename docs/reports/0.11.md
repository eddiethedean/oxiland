# Milestone 0.11 parity report

Status: in progress — infrastructure complete; cross-platform raw bundles still
required for a full claim

Milestone: [`0.11`](../milestones/0.11.md)

## Starting position

Oxiland 0.10 completed the public function inventory, implemented a broad C
surface, and checked in qualification scaffolding. The 0.10 checker passes its
own bundle, but that bundle does not prove the full compatibility contract.

The 0.11 phase treats all 0.10 `verified` states as candidates for
reverification, not inherited proof.

## Completion rule

This report becomes `complete` only when `scripts/check-0.11-release.py` derives
a passing result from linked raw evidence for every frozen target and profile.
Counts from an inventory, an export allowlist, or a manually asserted profile
result cannot close a gate.
