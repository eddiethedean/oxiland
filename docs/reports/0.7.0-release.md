## Commands

```console
cargo test
cargo clippy --all-targets -- -D warnings
cd python && maturin develop && pytest && pyright
```

Tagging triggers the Release workflow (`.github/workflows/release.yml`):
crates.io via `CARGO_REGISTRY_TOKEN`, PyPI **wheels only** via `PYPI_API_TOKEN`
(`maturin publish --no-sdist` / `MATURIN_PYPI_TOKEN`). Source distributions are
not published in 0.7.0 (path dependency on the Rust crate).
