## Commands

```console
cargo test
cargo clippy --all-targets -- -D warnings
cd python && maturin develop && pytest && pyright
```

Tagging triggers the Release workflow (`.github/workflows/release.yml`):
crates.io via `CARGO_REGISTRY_TOKEN`, followed by PyPI **wheels only** through
OIDC Trusted Publishing. The PyPI job downloads the exact wheels built and
install-smoked by CI; it does not rebuild them. Both registries skip versions
already present so a partial release can be rerun safely. Source distributions
are not published in 0.7.0 (path dependency on the Rust crate).
