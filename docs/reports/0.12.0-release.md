# Oxiland 0.12.0 release checklist

Status: tip preflight

Tag target: `v0.12.0`

## Release scope

0.12.0 closes the performance-optimization milestone: frozen competitive-parity
gate ([ADR-028](../DECISIONS.md#adr-028-012-competitive-parity-performance-gate)),
production-compile evidence on Linux/macOS/Windows `release-default`, RSS
budgets, and retained 0.11 parity on the candidate ancestry. See the
[0.12 report](0.12.md).

## Notes

The optimized tip beats genuine Redland in all ten corrected strict cases on
macOS/arm64, with paired confidence intervals beyond parity. Cite that result
with its host scope. Do not market a blanket cross-platform “faster than
Redland” claim until Linux, macOS, and Windows each pass three independent
runs. The earlier committed 0.12 evidence predates the runtime-library
isolation fix and is retained as a historical qualification record rather than
speed-claim evidence.
