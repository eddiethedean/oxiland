# Oxiland 0.6.0 release checklist

Preflight for tagging `v0.6.0`.

## Preflight

- [x] `Cargo.toml` version is `0.6.0` (library + `oxiland-cli`)
- [x] `CHANGELOG.md` has a dated `0.6.0` section
- [x] `docs/reports/0.6.md` describes the safe-API accounting claim
- [x] `PARITY.md` marks 0.6 complete and points at the 0.6 inventory
- [x] `docs/ROADMAP.md` / `docs/milestones/0.6.md` are `complete`
- [x] ADR-018–ADR-021 are accepted
- [x] Public API snapshot current; semver-checks vs 0.5.0 established
- [x] `oxiland-cli` example workflows + CI smoke
- [x] `SECURITY.md` supports `0.6.x`
- [x] `LICENSE-APACHE` and `LICENSE-MIT` are present
- [ ] Working tree clean on the release candidate tip after push
- [ ] CI on `main` green (Check + Fjall + MSRV + RDF I/O conformance)
- [ ] `cargo publish --dry-run` succeeded on the release candidate tip
- [ ] Pushed to `main`

## Publish

- [ ] Annotated tag `v0.6.0` pushed (`git tag -a v0.6.0 -m "oxiland 0.6.0"`)
- [ ] Release workflow completed successfully on the tag
- [ ] Publish `oxiland-cli` (same version) if not covered by the workspace release job

## After publish

- [ ] Confirm https://crates.io/crates/oxiland (0.6.0)
- [ ] Confirm https://crates.io/crates/oxiland-cli (0.6.0)
- [ ] Confirm https://docs.rs/oxiland builds
- [ ] Create a GitHub Release from the `v0.6.0` tag using `CHANGELOG.md`
